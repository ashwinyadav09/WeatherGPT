# Guidance library (ticket 10)

Curate short, cited guidance for heat waves and cold waves (later cyclone, flood, lightning).

1. Find the official source: NDMA guidelines and do's and don'ts, IMD advisories. Use official sites only.
2. For each hazard write at most eight short lines of what officials advise, in your own words, one idea per line.
3. Store entries as YAML: id, hazard, language, text, source_title, source_url, retrieved_on, reviewed (false until a person reviews it).
4. The app shows the source with every card. Never add advice that is not in the source.
5. A person must review each hazard's entries before release (human step); record the reviewer's name in the file.

Start with English; add Hindi after the English is reviewed.

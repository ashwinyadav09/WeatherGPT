# Add an alert template

1. Find the official wording (IMD, NDMA or the issuing authority) for the hazard and severity. Done when the source is linked in the template header.
2. Write the template with slots only for place and time.
3. Back-translate it and compare with the official meaning.
4. Add a snapshot test that renders the template for sample places and times.
5. Record a native-speaker sign-off in the ticket. This step needs a human.

Done means: snapshot green, back-translation matches, sign-off recorded.

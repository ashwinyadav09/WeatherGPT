# Team workflow

- Work for one named person (WHO in your prompt). Take only tickets assigned to them in team/assignments.csv.
- Never push to main. One ticket per branch named ticket/<NN>-<slug>; commits start with the ticket number; rebase on origin/main before the pull request.
- Stay inside your owner's folders (docs/team.md). For another person's folder, open an issue labelled needs:<owner> and use a stub or mock; do not edit it.
- Shared shapes live in packages/contracts. Change them only in a small pull request labelled contract.
- Add modules through the extension points (router.py discovery, config/sources.yaml, web feature folders); never edit shared registries by hand.
- Keep one Alembic head; if main moved, rebase and regenerate your migration.
- Edit only your own ledger in .scratch/weathergpt/progress/. PROGRESS.md is generated by `python scripts/dev.py progress`.
- Never commit keys, .env or raw data.

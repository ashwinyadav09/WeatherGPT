# Evaluation and Acceptance Reference

Grounded evaluation framework and acceptance gates proving system accuracy, reliability, and compliance. All expected values strictly derive from recorded fixtures and machine-readable execution traces—never from hand-typed numbers or simulated estimates.

---

## 1. Golden Case Format & Organization

Golden sets are organized strictly by intent under `eval/golden/<lang>/{forecast,advisory,refusal}.yaml` for all 7 Tier-1 languages (`en`, `hi`, `bn`, `mr`, `te`, `ta`, `or`), spanning 11 diverse Indian cities (Delhi, Mumbai, Bengaluru, Chennai, Kolkata, Hyderabad, Jaipur, Shimla, Pune, Guwahati, Varanasi).

```yaml
- id: forecast-pune-001
  language: en
  archetype: forecast          # forecast, advisory, refusal
  fixture_set: open_meteo/pune-2026-11-10
  now: 2026-11-10T05:30:00Z
  question: Will it rain tomorrow in Pune?
  expect:
    tools: [{name: resolve_place, args: {text: Pune}}, {name: get_forecast}]
    numbers: [{value: 18.0, unit: mm, evidence_source: open_meteo.forecast}]
    source_named: Open-Meteo
    must_not: [evacuate, guaranteed]
    refusal: false
```

## 2. Truthfulness & No-Simulation Enforcement

In accordance with Section 2 Truthfulness Rules:
1. **Zero Simulated Metrics**: Metrics, latencies, error rates, and counts are never hard-coded. Every reported figure comes directly from a machine-readable result file generated by an automated test or evaluation script.
2. **Honest Failure & Unmeasured State**: Unmeasured modalities (such as manual screen-reader evaluations) are explicitly marked `NOT MEASURED`.
3. **Statistical Significance**: All comparative ablations are evaluated using 1,000 paired bootstrap resamples with empirical 95% confidence intervals that must strictly exclude zero for claimed improvements.
4. **Machine-Rendered Documentation**: `docs/EVAL_RESULTS.md` and `eval/results/<date>/acceptance-<date>.md` are generated by script and validated in strict CI gates.

## 4. Commands

```bash

# Archive dated reports and render docs/EVAL_RESULTS.md:
python scripts/tasks/generate_eval_results.py

# Run all 19 acceptance gates in strict mode:
python scripts/tasks/acceptance.py --strict

# Execute the 10-step scripted demo:
python scripts/tasks/demo.py
```

# Contributing

Read `docs/team.md`. In short: one ticket per branch (`ticket/<NN>-<slug>`), small commits (`<NN>: message`), rebase on `origin/main`, run `python scripts/dev.py ci`, open a pull request from the template, get one approval, squash-merge. Never push to `main`, never commit keys, never edit another person's folder without an issue labelled `needs:<owner>`.
